\chapter{Introduction} \label{Chp:Introduction}
This manual describes the features of \QUICKPLOT.
The program can be used to visualise and animate numerical results produced by various components of the \dfmsuite, the \dhydrosuite, the \dfoursuite and the \sobeksuite and various other programs such as UNIBEST, SHIPMA and PHAROS.
The program has been developed using MATLAB.
The \DMATLAB\ interface contains a version of \QUICKPLOT\ that integrates seamlessly with the MATLAB environment.

\QUICKPLOT\ has been developed to be a user-friendly, flexible and robust tool for interactive data visualisation and animation.
For instance, all active buttons and edit fields have tool tips that provide online help.
Therefore, Chapter 2 contains only a short tutorial to get you familiar with the main program window for creating basic plots.
Chapter 3 describes all plot options.
Chapter 4 explains how to export and print figures.
Chapter 5 addresses the more advanced features of \QUICKPLOT.

\section{Version information}
This manual describes the functionality of \QUICKPLOT\ version 2.72 and later versions with minor revisions.

\QUICKPLOT\ is created using MATLAB and the MATLAB Compiler by The MathWorks, Inc..
This program requires technology of The MathWorks to run, a.o.\ the MATLAB Compiler Runtime (MCR) Libraries.
These MCR Libraries need to be installed as a separate step during the installation; they can be downloaded from \url{https://nl.mathworks.com/products/compiler/matlab-runtime.html}.
Make sure to install exactly the right version.
The current \QUICKPLOT\ version requires version 9.14 (MATLAB Release 2023a) of the MCR on Windows, version 23.2 (MATLAB Release 2023b) on Linux.
